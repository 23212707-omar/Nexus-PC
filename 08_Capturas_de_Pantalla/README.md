# Capturas de pantalla

Capturas de **Nexus PC** funcionando, con la versión final de la etapa. El número al inicio del nombre indica el orden.

| Números | Tema | Qué muestran |
|---|---|---|
| 01 a 07 | API | Prueba de conexión, servidor iniciado, categorías, productos por categoría, detalle de producto y errores `404` y `400` |
| 08, 09, 16, 17 | Catálogo | Procesadores y almacenamiento, incluido un producto agotado |
| 10, 27 a 29 | Vista móvil | Catálogo, carrito y compatibilidad en pantalla de celular |
| 11, 20 | Vista rápida del carrito | Panel bajo el botón "Carrito" del encabezado |
| 12 a 15 | Base de datos | Tablas en SSMS, total de productos, productos por categoría y estados de stock |
| 18, 19 | Detalle de producto | Producto con stock y producto agotado |
| 21 | Carrito completo | Pantalla `#/carrito` |
| 22, 23 | Compra | Errores de validación del formulario y pedido registrado |
| 24 a 26 | Compatibilidad | Lista de compatibles, aviso al agregar un incompatible y fuentes de poder |

Las pantallas están descritas en `../01_Codigo_Fuente/frontend/README.md` y las rutas de la API en `../04_Documentacion/Artefactos/API_Especificacion.md`.
