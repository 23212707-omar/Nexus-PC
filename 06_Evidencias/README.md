## Cómo se organiza

- Cada etapa del proyecto tiene su evidencia, con el número de etapa en el nombre del archivo.
- Las capturas del sistema funcionando (API, base de datos y página web) están en `../08_Capturas_de_Pantalla`.
- El seguimiento de tareas, issues y Pull Requests está en GitHub (Issues y GitHub Projects).
